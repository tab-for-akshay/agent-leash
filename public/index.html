Agent Leash

Give an AI agent money without giving it the keys. The purse is a NEAR contract. The agent holds only a function-call key that can call one method, request_payment. Every request is checked on-chain against the owner's rules: allowlist, per-payment cap, daily cap, human approval above a threshold, and a pause switch. The agent can be fooled; the purse can't.
